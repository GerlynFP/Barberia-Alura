# Barbería Alura

Sitio web de una barbería ficticia: inicio, servicios con precios y formulario de contacto. Proyecto de práctica de HTML y CSS, rediseñado para que sea responsivo y con animaciones suaves.

## Páginas

- **Inicio:** portada, historia y misión, servicios, ubicación, diferenciales y video.
- **Productos:** servicios con precios y botón para reservar.
- **Contacto:** formulario con validación y horario de atención.

## Detalles

- HTML, CSS y JavaScript sin librerías.
- Diseño responsivo para celular, tablet y escritorio.
- Animaciones al cargar y al hacer scroll, que respetan `prefers-reduced-motion`.
- El video de YouTube se carga solo al hacer clic, para que la página abra más rápido.
